About

This project is both a website and an AWS learning experiment.

Most cloud tutorials describe AWS services in the abstract. CloudLab AWS takes a different approach: the site you're using is itself the case study. Its own architecture — the network, the compute, the storage, the monitoring — is the curriculum.

The goal isn't to cover every AWS service that exists. It's to teach a focused set of them deeply enough that you understand not just what each one is, but why a real, working system needed it, and how it connects to everything around it.
