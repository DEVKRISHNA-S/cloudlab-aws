AWS Well-Architected Framework

Five pillars for evaluating any design

What is it?
A structured way to evaluate a cloud architecture against five pillars: Operational Excellence, Security, Reliability, Performance Efficiency, and Cost Optimization.
Why does it exist?
It's easy to build something that technically works. The Well-Architected Framework is how you check whether it also fails gracefully, stays secure, and doesn't quietly waste money.
How this project uses it
Run against this project: IAM roles (Security), a single EC2 instance with no redundancy (a Reliability gap worth naming), pay-per-use Lambda and S3 (Cost Optimization), and CloudWatch alarms (Operational Excellence).

The Problem

Without a shared framework, 'is this architecture good?' is just an opinion. The Well-Architected Framework gives every design the same five yardsticks to be measured against.

Important Concepts

Operational Excellence
Running and monitoring systems to deliver business value, and continuously improving processes.
Security
Protecting data, systems, and assets through risk assessments and mitigation strategies.
Reliability
The ability to recover from failures and consistently meet demand.
Performance Efficiency
Using computing resources efficiently as demand and technology evolve.
Cost Optimization
Avoiding unnecessary costs while still meeting business requirements.
AWS Trusted Advisor
An automated tool that checks your account against Well-Architected best practices and flags gaps.

Common Mistakes

  • Optimizing hard for one pillar (like cost) while ignoring the trade-offs it creates in another (like reliability).
  • Treating the framework as a one-time audit instead of an ongoing practice.
  • Ignoring AWS Trusted Advisor recommendations because they seem minor.
  • Assuming 'it works in testing' is the same as 'it's reliable in production'.

Mini Challenge

You now understand:
  • The framework measures a design against five independent pillars
  • Trade-offs between pillars are normal and should be deliberate, not accidental
  • Trusted Advisor automates part of this evaluation continuously
