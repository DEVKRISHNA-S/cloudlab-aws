IP Addressing & Subnetting

Carving a network into pieces

What is it?
Subnetting splits one large block of IP addresses into smaller, purpose-built pieces — exactly what a VPC's public and private subnets are doing.
Why does it exist?
A single flat network doesn't let you separate 'internet-facing' resources from 'internal-only' ones, and it wastes addresses. Subnetting (via FLSM and VLSM) fixes both.
How this project uses it
This project's VPC (10.0.0.0/16) is subnetted into a public subnet (10.0.1.0/24) for EC2 and a private subnet (10.0.2.0/24) reserved for internal services — the same math taught in this module.

The Problem

Without subnetting, every device would share one enormous broadcast domain, and there'd be no clean way to separate public from private resources. Carving address space into right-sized subnets solves both problems at once.

From one block to many

1Start with a block, e.g. 10.0.0.0/16 (65,536 addresses)
2Decide how many subnets you need
3Borrow bits from the host portion to create subnet boundaries
4FLSM gives every subnet the same fixed size
5VLSM sizes each subnet to what it actually needs, wasting fewer addresses

Important Concepts

IP address
A numeric address identifying a device on a network.
CIDR notation
A slash number (e.g. /24) indicating how many bits are fixed for the network portion.
FLSM
Fixed-Length Subnet Masking — every subnet carved from the block is the same size.
VLSM
Variable-Length Subnet Masking — subnets are sized individually, matching real demand.
Network vs. host bits
The network portion identifies the subnet; the host portion identifies a device within it.
Broadcast address
The reserved address at the top of a subnet used to reach every device on it at once.

Common Mistakes

  • Forgetting that the first and last address in a subnet are reserved (network and broadcast).
  • Using FLSM when subnet sizes actually vary a lot, wasting large blocks of addresses.
  • Miscounting borrowed bits and ending up with the wrong number of usable hosts.
  • Assuming a bigger CIDR block number means a bigger network — it's the opposite.
