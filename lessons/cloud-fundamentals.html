Cloud & AWS Fundamentals

Why the cloud, and what it costs

What is it?
The foundational business and pricing concepts behind cloud computing — what you're actually paying for, and how AWS structures accounts, billing, and support.
Why does it exist?
Every later module assumes you understand why teams move to the cloud at all, and how to avoid an unpleasant billing surprise once real resources exist.
How this project uses it
This project itself follows AWS's pay-as-you-go model — every service in it (EC2, S3, Lambda...) bills only for what's actually used, which is exactly the fundamental promise of the cloud.

The Problem

Owning physical infrastructure means paying for peak capacity year-round, even when you only need it occasionally. Cloud computing solves this by renting exactly the capacity you need, only when you need it.

Important Concepts

Cloud computing
On-demand access to computing resources over the internet, without owning the hardware.
Elasticity
The ability to scale resources up or down automatically as demand changes.
Total Cost of Ownership (TCO)
The full cost of running infrastructure yourself — hardware, power, staff, and space — compared against the cloud alternative.
AWS Simple Monthly Calculator
A tool for estimating what a given AWS architecture will cost before you build it.
AWS Organizations
A way to centrally manage billing and policies across multiple AWS accounts.
Billing Dashboard
The AWS console view showing current spend, forecasts, and cost breakdowns.
Support plans
Tiers of AWS technical support, from basic (self-service) to enterprise (dedicated response times).

Common Mistakes

  • Comparing only sticker price per hour instead of full total cost of ownership.
  • Not setting billing alerts before starting to experiment with real resources.
  • Assuming the cheapest support plan is always the right choice, regardless of business risk.
  • Ignoring AWS Organizations when managing more than one AWS account.

Mini Challenge

You now understand:
  • Cloud computing trades owned infrastructure for on-demand, pay-as-you-go capacity
  • TCO — not just hourly price — is the honest cost comparison
  • AWS Organizations and billing alerts keep multi-account spend under control
