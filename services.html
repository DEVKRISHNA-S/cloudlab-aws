How This Website Works

One request, nine services

Here's the complete path a single visit takes through this project's real infrastructure.

1A visitor enters the domain in their browser.
2Route 53 resolves the domain to the application's address.
3The connection is encrypted over HTTPS.
4Traffic enters the VPC through its networking rules.
5The EC2 instance handles the core application workload.
6Selected requests are routed through API Gateway to Lambda.
7S3 serves and stores static assets and backups.
8IAM roles gate every one of those requests to only what's needed.
9CloudWatch collects logs and metrics from all of the above.

What Would This Cost?

AWS pricing varies by region, usage, instance type, storage, and request volume — so exact numbers aren't shown here. What matters is understanding what actually drives the bill for each service.

ServiceMain cost driver
EC2Instance runtime
S3Storage + requests
LambdaInvocations + compute duration

Always delete resources you no longer need.
When experimenting in a real AWS account, set up AWS Budgets and billing alerts before you start — not after the first surprising invoice.
